# Simple Social TUI

A full-screen terminal UI for the Simple Social API, built on ncurses.

Sibling to `simple-social-cli` (argv-style CLI) and `simple-social-cli-interactive`
(wizard-style REPL). Planned to link against `simple-social-cli`'s `lib/libss.so` and
share login/session state via `~/.simple-social-cli/`.

Status: planning. Nothing implemented yet.
